# A Little Something For You

A small interactive gift site: asks your name, asks if it can flirt with you, then shows three rotatable 3D bouquets (tulips, a garden box, wildflowers) rendered in raw WebGL.

Built with React + Vite. No backend; answers stay on the device and are never sent anywhere.

## Run locally

```
npm install
npm run dev
```

## Build

```
npm run build
```
